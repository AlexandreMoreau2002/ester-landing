# Local SEO Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Unifier les signaux techniques SEO autour de `https://ester-sas.fr` et rendre les données LocalBusiness valides.

**Architecture:** Le serveur Node appliquera une redirection permanente de `www` vers le domaine nu. Les documents HTML et d'exploration utiliseront le même hôte, et le test unitaire vérifiera le contrat HTTP et le JSON-LD.

**Tech Stack:** Node.js HTTP, Vite static build, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-03-local-seo-design.md`

## Global Constraints

- Ne pas créer de compte Google ni modifier une fiche externe sans le représentant ESTER.
- Le formulaire de contact et les routes API restent fonctionnels après redirection.
- Aucune donnée de référencement n'est inventée.

## Review Focus

- Une requête `POST /api/contact` sur `www` doit conserver sa méthode grâce au code 308.
- Les requêtes sur l'hôte canonique et sur `localhost` ne doivent jamais être redirigées.
- Chemin et query string doivent survivre à la redirection.
- Chaque URL exposée dans robots et sitemap doit employer le domaine nu.
- Le contenu JSON-LD doit rester parseable par `JSON.parse`.
